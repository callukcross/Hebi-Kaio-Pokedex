# Pokedex5E data source

`filter_data.json`, `evolve.json`, and `items.json` are derived from the `p5e-data` submodule used by [Jerakin/Pokedex5E](https://github.com/Jerakin/Pokedex5E), checked at submodule commit `519adc38da6eefa57b74fb403f1d7dbf596f4046`. `feats.json` and `leveling.json` come from the same reference application's data files.

The parent reference project is distributed under GPL-3.0. Pokémon names and related properties belong to their respective rights holders. These files are retained as application data for compatibility with the referenced Pokémon 5e ruleset.
